# Contributing to PyCompiler ARK

Contributions to PyCompiler ARK are welcome through pull requests.  
Please create a dedicated branch for your changes and keep commits clear and focused.

## Workflow

1. Create a branch from the target branch.
2. Make focused commits with meaningful messages.
3. Sign commits using `git commit -s`.
4. Open a pull request against the appropriate branch.
5. Review changes before merging.

## Getting Started

If you want to extend PyCompiler ARK, start with these guides:

- **Application i18n**: [app_i18n.md](https://github.com/raidos23/PyCompiler_ARK/blob/main/docs/app_i18n.md)
- **Creating a Compilation Engine**: [how_to_create_an_engine.md](https://github.com/raidos23/PyCompiler_ARK/blob/main/docs/how_to_create_an_engine.md)
- **Creating a Pre-Compile Plugin**: [how_to_create_a_bc_plugin.md](https://github.com/raidos23/PyCompiler_ARK/blob/main/docs/how_to_create_a_bc_plugin.md)

For translation work, read the application guide first, then the engine or plugin guide related to the area you are modifying.
