Technical Features

Dependency Auto-Mapping

Automatic configuration for third-party libraries through the built-in dependency analyzer.

Internal Module Apply

`init --apply-internal` can prefill `build.include` for internal project modules, with confirmation or `-y`.

Build Locking

Saves Git state and library versions to ensure reproducible rebuilds from lock files.

BCASL Pipeline

Execution of custom actions and checks before the build phase through BCASL plugins.
